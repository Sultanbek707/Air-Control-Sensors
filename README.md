# Air Control Sensors 🌫️

Веб-приложение, которое показывает качество воздуха в районах Шымкента.

## Как запустить у себя

1. Установите Python 3.10 или новее.
2. Скачайте проект (Code → Download ZIP или через GitHub Desktop).
3. Откройте терминал в папке проекта и выполните:

```
pip install -r requirements.txt
streamlit run app.py
```

4. В браузере откроется приложение (обычно http://localhost:8501).

## Кто за что отвечает

| Папка / файл | Подкоманда |
|---|---|
| `app.py` | Фронтенд — Султан |
| `backend/` | Бэкенд — Азизбек |
| `ai/` | AI — Мафтуна |
| `tests/` | Тестировщики — Талшын |

Правило: работайте только в своей папке. В `main` напрямую не пишем.

## Договорённость фронтенда и бэкенда

Фронтенд берёт данные только через функцию `get_hourly(district)` из `backend/data.py`.
Она возвращает таблицу с колонками `time, pm2_5, pm10, no2, aqi` и источник (`"api"` или `"demo"`).
Бэкенд может менять всё внутри функции, но не её название и формат ответа.
